# C++ Object-Oriented Programming & Fundamentals Practice

This repository contains a structured collection of C++ implementations covering fundamental programming concepts, advanced Object-Oriented Programming (OOP) paradigms, and class/lab coursework tasks.

## 📌 Topics Covered

### 1. Object-Oriented Programming (OOP)
* **Classes & Objects:** Data encapsulation, getters/setters, static members, constructors, destructors, constructor overloading.
* **Inheritance:** Single, multi-level, multiple, hierarchical, hybrid, and virtual inheritance.
* **Polymorphism & Abstraction:** Function/method overloading, function overriding, virtual functions, abstract classes.
* **Associations:** Composition, aggregation.
* **Advanced Features:** Friend functions (single/multiple classes), operator overloading (`=`, `+=`, custom operators), `this` pointer concepts.

### 2. Core C++ Fundamentals & Data Structures
* **Arrays & Matrices:** 1D arrays, 2D arrays, array of objects.
* **Memory & Pointers:** Pointers, reference variables, pass by value vs. pass by reference.
* **Structures & Types:** Enums, unions.
* **Exception Handling:** Try-catch blocks, custom exception handling.
* **File Handling:** Reading, writing, and file execution processes.
